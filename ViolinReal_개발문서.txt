1. 프로젝트 개요
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 이름: Violin Real (웹 바이올린 시뮬레이터)
- 참고 앱: Google Play / App Store의 "Violin Real" (개발자: Son Truong Ngoc)
- 파일: 단일 HTML 파일 (ViolinReal.html)
- 기술: HTML5 Canvas API + Web Audio API (외부 라이브러리 없음)
- 타겟: 갤럭시 플립 (세로로 긴 좁은 화면) 모바일 최적화
- 입력: 터치 + 마우스 (pointerdown/move/up)

[레이아웃]
• 헤더: 앱 이름 + FreePlay 모드 표시
• 핑거보드 영역 (상단):
  - 좌측: 개방현 버튼 4개 (G3 초록, D4 보라, A4 시안, E5 노랑)
  - 우측: 7행 × 4열 노트 버튼 그리드 (반음 1~7)
  - 버튼은 반투명, 뒤로 에보니 지판이 비침
• 활 영역 (하단, 화면의 약 60%):
  - 바이올린 본체 그래픽 (C자 허리, 상·하 바우트, F홀, 브릿지)
  - 세로 현 4줄 (핑거보드 현과 동일한 X좌표에 연속)
  - 활 그래픽 (나무 스틱, 활털, 프로그, 팁) — 대각선으로 손가락 따라 이동

[배경 그래픽]
• 전체 화면 배경 캔버스 (bgCv):
  - 나무결 벽면 (메이플 텍스처)
  - 에보니(흑단) 지판 사다리꼴
  - 바이올린 본체 (스프루스/메이플 나뭇결, 퍼플링)
  - F홀 (실제 f자 곡선)
  - 너트, 브릿지, 테일피스, 턱받침
  - 현 4줄이 위→아래로 끊김 없이 관통

[오디오 엔진]
• 1순위: 실제 바이올린 녹음 샘플 (GitHub tonejs-instruments)
  - G3, A3, C4, E4, G4, A4, C5, E5, G5, A5, C6 총 11개 mp3
  - 가장 가까운 샘플을 찾아 playbackRate로 피치 시프트
  - 루프 재생 (활로 길게 켤 때 끊김 없음)
• 2순위 (폴백): Web Audio API 합성
  - 9개 사인파 배음열 (바이올린 스펙트럼 기반)
  - 피킹 필터로 바디 공명 시뮬레이션 (400Hz)
  - 로우패스 필터 (활 속도에 따라 변조)
  - ADSR 엔벨로프
• 리버브: 딜레이 네트워크 기반 (28ms + 48ms, 피드백 20%)

[인터랙션]
• 핑거보드 노트 버튼: 터치하면 해당 현의 반음 선택
• 개방현 버튼: 터치하면 해당 현 0번 포지션(개방현) 선택
• 활 드래그: 하단 영역에서 자유롭게 2D 드래그
  - 좌우 이동 시 세로 현을 가로지르며 소리 발생
  - 현 교차 시 자동으로 현 전환
  - 드래그 속도 → 음량 조절
  - 드래그 방향 → 활 기울기 변화

[시각 효과]
• 활성 현: 컬러 빛줄기 (초록/보라/시안/노랑)
• 현 진동: 사인파 애니메이션
• 접촉점: 글로우 이펙트 + 로진 자국
• 파티클: 현 전환 시 스파크
• 활 그래픽: 프로그(진주 눈, 실버 감기), 스틱(나무 그라데이션), 팁

3. 개발 과정에서 겪은 문제 & 해결
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[문제] 활이 안 움직임
→ 원인: 배경 캔버스(bgCv)가 absolute로 화면 전체를 덮으면서 터치 이벤트 가로챔
→ 해결: bgCv에 pointer-events:none 추가

[문제] addColorStop 에러 (rgba 문자열 파싱 실패)
→ 원인: SC[i]가 '#ffdd33' 같은 hex인데 rgba() 문자열과 잘못 결합됨
→ 해결: SCA 배열로 'rgba(255,221,51,' 프리픽스를 미리 계산

[문제] 코드 버튼 누른 후 잔상이 남음
→ 원인: hlBtns()가 선택된 노트를 계속 .on 클래스로 유지
→ 해결: hlBtns() 삭제, CSS :active와 수동 add/remove만 사용

[문제] 소리가 전자음 (바이올린답지 않음)
→ 원인: 원래 sawtooth 오실레이터 사용
→ 해결: 사인파 배음열(9개) + 바디 공명 필터 + 활 노이즈로 교체, 
         추가로 실제 바이올린 샘플 로딩 시도

[문제] 외부 샘플 fetch 차단 시 소리 안남
→ 원인: 샘플 로딩 에러가 전체 오디오 init을 깨뜨림
→ 해결: loadSamples().catch(()=>{})로 에러 무시, 합성 엔진 항상 우선 작동

[문제] 개방현 버튼이 활 영역에 있어서 드래그 방해
→ 해결: 핑거보드 좌측 열로 이동

[문제] 현 위치가 핑거보드/활 영역에서 안맞음
→ 해결: globalStrX() 단일 함수로 전체 화면 통일

[문제] 바이올린이 기타처럼 생김
→ 해결: bezierCurveTo로 C자 허리, 상·하 바우트 정확히 구현

---프롬프트 시작---

첨부된 ViolinReal.html은 Violin Real 앱을 모방한 웹 바이올린 시뮬레이터야.
단일 HTML 파일이고, Canvas API + Web Audio API로 구현됨.
갤럭시 플립 세로 화면 최적화.

현재 구조:
- 상단: 핑거보드 (좌측 개방현 버튼 4개 + 우측 7×4 노트 그리드)
- 하단: 활 드래그 영역 (바이올린 본체 + 세로 현 4줄 + 대각선 활 그래픽)
- 배경: 전체 화면 캔버스에 에보니 지판, 바이올린 본체, 나무결 등
- 오디오: 실제 샘플(GitHub) 우선, 실패 시 합성 엔진 폴백

아래 항목들을 개선해줘:

1. [소리 개선]
   - 현재 합성 소리가 아직 전자음 느낌이 남아있음
   - 활 속도에 따른 음색 변화를 더 자연스럽게 (느리면 부드럽고, 빠르면 거친 소리)
   - 활 방향 전환(up-bow ↔ down-bow) 시 미세한 어택 변화
   - 비브라토를 핑거보드 위에서 좌우 떨림으로 조절할 수 있게
   - 피치카토(현 뜯기) 모드 추가 — 활 대신 탭으로 뜯는 소리

2. [Violin Real 앱의 추가 기능들]
   - Simple / Professional / No Bow 3가지 모드 전환
   - Simple: 오른손만 (활 드래그 또는 터치로 소리)
   - Professional: 양손 (왼손 핑거보드 + 오른손 활) — 현재 구현된 것
   - No Bow: 핑거보드 버튼만 눌러서 소리
   - 곡 연습 모드 (악보 따라 연주, 자동 재생)
   - 녹음 / 재생 기능

3. [비주얼 개선]
   - 활이 현에 닿을 때 현이 약간 눌리는 애니메이션
   - 활 압력(터치 세기 또는 드래그 속도)에 따른 현 눌림 정도
   - 핑거보드의 현재 선택된 포지션에 손가락 표시
   - 연주 중인 음 이름을 더 크게, 오선지 위치로도 표시

4. [UX 개선]
   - 핑거보드 노트 버튼 크기/간격을 갤럭시 플립에서 더 편하게
   - 노트 버튼에 1st position, 2nd position 등 포지션 표시
   - 활 영역에서 더블탭 → 피치카토 전환
   - 설정 버튼 (음량, 리버브 양, 바이올린 종류 선택)

5. [곡 시스템]
   - 내장 곡 최소 3개 (Twinkle Twinkle, Ode to Joy, Minuet in G)
   - 곡 데이터: {string, semitone, duration, timing} 배열
   - 노트가 내려오는 리듬 게임 모드
   - 악보 표시 모드 (간이 오선지)

6. [기술 제약]
   - 반드시 단일 HTML 파일로 유지
   - 외부 라이브러리 사용 금지 (Canvas + Web Audio만)
   - 터치/마우스 모두 지원
   - 60fps 유지
   - 갤럭시 플립 (세로 긴 화면) 최적화 유지

기존 코드의 레이아웃과 디자인은 유지하면서 위 기능들을 추가해줘.
특히 활의 자유도(2D 이동)와 바이올린 형태(C자 허리)는 절대 바꾸지 마.

├── <body>
│   ├── #bgCv — 전체 배경 캔버스 (바이올린 본체 + 지판)
│   ├── #hd — 헤더바
│   ├── #fb — 핑거보드 영역
│   │   ├── #osCol — 개방현 버튼 열
│   │   └── #noteArea — 노트 그리드 (shdr + ng)
│   ├── #bz — 활 영역
│   │   ├── #bowCv — 활 오버레이 캔버스
│   │   ├── #nd — 현재 음 표시
│   │   └── #logo
│   └── #ov — 시작 오버레이
└── <script>
    ├── AE — 오디오 엔진 (샘플 + 합성 폴백)
    ├── 상태 변수 (semi[], actS, bow, vib[], parts[])
    ├── buildFB() — 핑거보드 UI 생성
    ├── buildOS() — 개방현 버튼 생성
    ├── drawBG() — 배경 바이올린 렌더링
    ├── renderBow() — 활 + 현 진동 + 파티클 렌더링
    ├── strX(i) — 전역 현 X좌표 계산
    ├── 포인터 이벤트 핸들러 (bowCv)
    └── frame() — 메인 루프 (60fps)
